# Новые функции образовательной платформы

## 🎨 1. Темная тема

### Описание
Добавлена полноценная поддержка темной темы с плавным переключением.

### Функционал
- Кнопка переключения темы в навигационном меню (иконка луны/солнца)
- Автоматическое сохранение выбранной темы в localStorage
- Плавные переходы между темами
- Адаптированные цвета для всех элементов интерфейса

### Технические детали
- CSS переменные для светлой и темной темы
- JavaScript для переключения и сохранения настроек
- Файлы: `templates/base.html`, `static/css/style.css`

---

## 🔥 2. Система стриков (заходов дней подряд)

### Описание
Система отслеживания ежедневной активности пользователей.

### Функционал
- Автоматическое обновление стрика при каждом заходе на главную страницу
- Отображение текущего стрика (дней подряд)
- Отображение лучшего стрика за все время
- Дата последней активности

### Где отображается
- Главная страница (dashboard) - в приветственном блоке
- Профиль студента - отдельная секция со статистикой

### Технические детали
- Модель: `UserStreak` (models.py)
- Функция обновления: `update_user_streak()` (app.py)
- API endpoint: `/api/user/streak`
- Автоматический вызов при загрузке dashboard

---

## 🏆 3. Система достижений

### Описание
Геймификация обучения через систему достижений за различные активности.

### Список достижений

#### Тесты
- 🎯 **Первый тест** - Пройдите первый тест
- 📚 **Знаток** - Пройдите 10 тестов
- 🏆 **Эксперт** - Пройдите 50 тестов
- 💯 **Отличник** - Получите 100% на тесте

#### Тренировки
- 💪 **Первая тренировка** - Завершите первую тренировку
- 🔥 **Спортсмен** - Завершите 10 тренировок
- ⚡ **Атлет** - Завершите 50 тренировок

#### Стрики
- 📅 **Неделя подряд** - Заходите 7 дней подряд
- 🌟 **Месяц подряд** - Заходите 30 дней подряд
- 👑 **Легенда** - Заходите 100 дней подряд

### Где отображается
- Главная страница - счетчик достижений
- Профиль студента - полный список с прогрессом
- Заблокированные достижения показаны серым цветом

### Технические детали
- Модели: `Achievement`, `UserAchievement` (models.py)
- Функции проверки:
  - `check_test_achievements()` - вызывается после прохождения теста
  - `check_training_achievements()` - вызывается после тренировки
  - `check_streak_achievements()` - вызывается при обновлении стрика
- API endpoint: `/api/user/achievements`
- Автоматическая инициализация при запуске приложения

## 📱 4. Мобильная адаптация мессенджера

### Описание
Полная адаптация интерфейса мессенджера для мобильных устройств.

### Функционал
- Адаптивная навигация между списком диалогов и чатом
- Кнопка "Назад" для возврата к списку диалогов
- Оптимизированные размеры элементов для сенсорных экранов
- Увеличенные области нажатия

### Брейкпоинты
- **768px и меньше**: Мобильный режим с переключением между экранами
- **480px и меньше**: Дополнительная оптимизация для маленьких экранов

### Технические детали
- CSS медиа-запросы в `templates/messenger.html`
- JavaScript функция `backToConversations()` для навигации
- Обновленная функция `loadConversation()` с поддержкой мобильных устройств
