# Краткая инструкция по новым функциям

## ✅ Что было добавлено

### 1. 🌙 Темная тема
- Кнопка переключения в навигации (справа)
- Автоматическое сохранение выбора
- Плавные переходы между темами

### 2. 🔥 Система стриков
- Отслеживание заходов дней подряд
- Отображение на главной странице и в профиле
- Автоматическое обновление при каждом заходе

### 3. 🏆 Система достижений (10 штук)
**Тесты:** Первый тест, 10 тестов, 50 тестов, 100% результат
**Тренировки:** Первая тренировка, 10 тренировок, 50 тренировок
**Стрики:** 7 дней, 30 дней, 100 дней подряд

### 4. 📱 Мобильная адаптация мессенджера
- Адаптивная навигация
- Кнопка "Назад" на мобильных
- Оптимизированные размеры

### 5. ✨ Новые иконки предметов
Обновлены все иконки в тестах на более красивые

## 🚀 Как запустить

```bash
# Инициализация (если еще не запускали)
python init_new_features.py

# Запуск приложения
python app.py
```

## 📍 Где смотреть

- **Темная тема**: Кнопка луны/солнца в навигации
- **Стрики**: Главная страница (dashboard) - в приветственном блоке
- **Достижения**: Профиль студента - полный список
- **Мессенджер**: Откройте на телефоне или уменьшите окно браузера
- **Иконки**: Страница "Тесты" - выбор предмета

## 🔧 Технические детали

### Новые файлы
- `init_new_features.py` - скрипт инициализации
- `НОВЫЕ_ФУНКЦИИ.md` - полная документация

### Измененные файлы
- `models.py` - добавлены 3 новые модели
- `app.py` - добавлены функции для стриков и достижений
- `templates/base.html` - кнопка темной темы
- `templates/dashboard.html` - отображение стриков
- `templates/student_profile.html` - достижения и стрики
- `templates/messenger.html` - мобильная адаптация
- `static/css/style.css` - темная тема
- `data/subjects_topics.json` - новые иконки

### API endpoints
- `GET /api/user/streak` - получить стрик
- `GET /api/user/achievements` - получить достижения
