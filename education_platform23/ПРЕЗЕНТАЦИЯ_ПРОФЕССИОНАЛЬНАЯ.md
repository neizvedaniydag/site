## 🚀 Как использовать

### Открыть презентацию
Файл уже открыт в браузере. Если нужно открыть снова:
```bash
open "/Users/temirlanrasidov/Downloads/education_platform2 3/presentation_pro.html"
```

### Сделать скриншоты
1. **Прокрути страницу** вниз - каждый слайд 1920x1080px
2. **Cmd + Shift + 4** → **Пробел** → клик на окно
3. Или используй полноэкранный режим (F11) и **Cmd + Shift + 3**

### Рекомендации
- Используй Chrome для лучшей поддержки CSS
- Масштаб 100% (Cmd+0)
- Отключи расширения (режим инкогнито)
- Подожди 1-2 секунды перед скриншотом
